# Quickstart / Szybki start

## English

Backend:

```bash
cd backend
python -m venv venv
```

Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source venv/bin/activate
```

Then:

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Frontend:

```bash
cd frontend
npm install
npm start
```

Open:

- `http://localhost:4200`
- `http://localhost:8000/docs`
