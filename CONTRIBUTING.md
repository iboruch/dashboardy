# Contributing / Współtworzenie

## English

Thanks for contributing to Dashboardy.

### Development flow

1. Fork the repository.
2. Create a feature branch.
3. Run the backend and frontend locally.
4. Make focused changes.
5. Open a pull request with a short explanation and screenshots when UI changes are involved.

### Before opening a PR

- make sure the app boots locally
- verify frontend build passes
- keep secrets out of the repository
- update docs when setup or behavior changes

### Good first contribution ideas

- improve loading and error states
- replace demo data with backend responses
- add tests for auth/data services
- improve self-hosting and deployment docs

## Polski

Dzięki za współtworzenie Dashboardy.

### Przepływ pracy

1. Zrób fork repozytorium.
2. Utwórz osobny branch na zmianę.
3. Uruchom lokalnie backend i frontend.
4. Wprowadzaj małe, konkretne zmiany.
5. Otwórz pull request z krótkim opisem i screenshotami, jeśli zmieniasz UI.

### Przed otwarciem PR

- upewnij się, że aplikacja uruchamia się lokalnie
- sprawdź, czy build frontendu przechodzi
- nie wrzucaj sekretów do repo
- aktualizuj dokumentację, jeśli zmienia się setup albo zachowanie aplikacji

### Dobre pierwsze zadania

- poprawa loading/error states
- podmiana demo danych na realne odpowiedzi z backendu
- dodanie testów dla auth/data services
- poprawa dokumentacji self-hostingu i deployu
